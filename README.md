## ติดตั้งและรันบน macOS

ทำตามขั้นตอนนี้ในแอป Terminal โดยใช้ [Homebrew](https://brew.sh/) สำหรับติดตั้งโปรแกรม หากยังไม่มี Homebrew ให้ติดตั้งก่อน

### 1. ติดตั้งโปรแกรมที่ใช้

```sh
brew install php@8.3 composer postgresql@16
```

โครงการนี้ใช้ PHP 8.3, Composer และ PostgreSQL สำหรับการรันในเครื่อง ไม่ต้องติดตั้ง Apache, Node.js หรือ npm

### 2. เตรียมฐานข้อมูล

หากใช้ PostgreSQL ในเครื่อง ให้เริ่มบริการ:

```sh
brew services start postgresql@16
```

นำฐานข้อมูลของโครงการมากู้คืนใน PostgreSQL และเตรียมชื่อผู้ใช้กับรหัสผ่านที่เข้าถึงฐานข้อมูลได้ **โครงการนี้ไม่มีไฟล์สำหรับสร้างตารางฐานข้อมูล** หากมี PostgreSQL อยู่บนเซิร์ฟเวอร์อื่นแล้ว ให้ใช้ฐานข้อมูลนั้นและข้ามคำสั่งเริ่มบริการด้านบน

### 3. ตั้งค่าการเชื่อมต่อฐานข้อมูล

เปิด Terminal ในโฟลเดอร์โครงการ แล้วรัน:

```sh
cp .env.example includes/.env
```

เปิดไฟล์ `includes/.env` แล้วกรอกค่าจริง เช่น:

```dotenv
DB_HOST=localhost
DB_USERNAME=ชื่อผู้ใช้ฐานข้อมูล
DB_PASSWORD=รหัสผ่านฐานข้อมูล
DB_DATABASE=ชื่อฐานข้อมูล
DB_PORT=5432
```

แอปอ่านค่าจาก `includes/.env` ดังนั้นต้องแก้ไฟล์นี้ แม้จะมี `.env` อยู่ที่โฟลเดอร์หลักก็ตาม

### 4. ติดตั้งไลบรารี PHP

รันคำสั่งนี้ในโฟลเดอร์โครงการ:

```sh
composer install
```

### 5. เปิดเว็บไซต์

รันคำสั่งนี้จากโฟลเดอร์โครงการ:

```sh
$(brew --prefix)/opt/php@8.3/bin/php -S localhost:8000 .dev/router.php
```

เปิด [http://localhost:8000/](http://localhost:8000/) ในเบราว์เซอร์ หากยังไม่เข้าสู่ระบบ ระบบจะพาไปหน้าเข้าสู่ระบบ โดยต้องใช้บัญชีผู้ใช้ที่อยู่ในฐานข้อมูลของโครงการ ไฟล์ `.dev/router.php` ช่วยให้ URL แบบ `/login` ใช้งานได้ กด `Ctrl+C` ใน Terminal เมื่อต้องการหยุดเซิร์ฟเวอร์
